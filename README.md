To-Do List Application

Project Overview:
-----------------
The To-Do List Application is a simple command-line program to help users manage tasks.
It allows users to:
- Add tasks to the list.
- View all current tasks.
- Remove completed tasks from the list.
- Exit the application when done.

Features:
---------
- Task management (add, view, and remove tasks).
- Interactive menu interface for easy navigation.
- Input validation for task addition and removal.

Setup Instructions:
-------------------
1. Ensure Python 3.x is installed on your system. Download from https://www.python.org/downloads/ if needed.

2. Clone or create a new Python file with the code provided.

   To clone (if using a repository):
   $ git clone https://github.com/yourusername/todo-list.git
   $ cd todo-list

   Or simply copy and paste the code into a `.py` file (e.g., `todo.py`).

3. Open your terminal and navigate to the folder containing the Python file.

4. Run the script with the following command:

   $ python todo.py
